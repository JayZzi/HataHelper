# 🏗️ Архитектура и бизнес-цели

## Бизнес-цели
1. **Сбор данных:** Фоновый парсинг объявлений с Realt.by (с заделом на Onliner).
2. **Аналитика и тегирование:** Фильтрация "бабушатников", автоопределение качественного ремонта, отслеживание динамики цен по районам.
3. **Оперативность:** Оповещения в Telegram о лучших вариантах в течение нескольких минут после публикации.
