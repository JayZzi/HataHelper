# 🏠 HataHelper

## 🚀 Технологический стек

* **Frontend:** Next.js, React, Tailwind CSS, Radix UI
* **Mobile:** React Native / Expo
* **Backend & Scraper:** Node.js, Express / NestJS, Cheerio, Axios
* **Database:** MongoDB + Mongoose, Mongo Express
* **Monorepo:** Turborepo, pnpm workspaces, Docker Compose

## ⚡ Быстрый старт
